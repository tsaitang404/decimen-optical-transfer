# 隐私

**除了以光的形式，什么都不被传送到任何地方。** 没有账号、没有配对、没有分析，设备之间没有网络路径——首次访问后断网也能工作。

**信道不保密。** 发送屏幕上显示的任何内容，任何对准它的摄像头都能读到。Decimen 给你的是*无网络*，不是加密。别在你不信任的房间里流式传输机密。

**完整性有校验。** 每个收到的文件在提供之前都会对照其 SHA-256 校验；损坏的流会响亮地失败，而不是交给你损坏的字节。

## 接收设备上持久化了什么

- **文本片段：什么都不留。** 显示时带一个复制按钮，标签页关闭就没了。
- **你保存的文件** 会去浏览器放下载的地方。
- **接收到的媒体**（视频/音频，这样页内播放器可以拖动进度）暂存在浏览器的 Cache API 里，否则会一直留到下一次传输覆盖它。*接收另一个文件*旁边的**清除 Decimen 缓存**按钮会当场删除它——把手机交给别人之前用它。
- service worker 的离线缓存保存的是**应用本身**，绝不保存传输内容。
