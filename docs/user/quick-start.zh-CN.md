# 快速开始

1. 在两台设备上都打开 [decimen.app](https://decimen.app/)。
2. 在发送设备（笔记本电脑最理想）上：**发送**，选一个文件。QR 码流立刻开始。把屏幕亮度调到最高。
3. 在接收设备（手机）上：**接收**，点**启动摄像头**，对准码流。让摄像头画面填满整个码，把手机靠在什么东西上。
4. 进度条走完后，文件出现，带预览和一个**保存**链接——前提是它的 SHA-256 校验通过。

想发文本而不是文件？把发送端切到**文本片段**并粘贴。接收端无论哪种都是同一个页面。

什么都解不出来？见[故障排查](troubleshooting.zh-CN.md)。

## 自己运行

```bash
npm install
npm run dev     # https 开发服务器 —— 自签名证书警告点一次
```

在发送端打开 `https://localhost:5173/send/`，在手机上打开打印出来的 `Network` URL（`https://<lan-ip>:5173/receive/`）。开发服务器只支持 https，因为浏览器会在不安全源上移除摄像头 API——细节和所有其他运行方式见[安装与离线](install-and-offline.zh-CN.md)。
