# 发送

打开 `/send/`。两种模式，在顶部切换：**文件**和**文本片段**。

- **文件** — 点**选择文件**（任意最大 64 MB 的文件）。流式传输立刻开始；按钮变成**停止传输**。只有当 gzip 确实缩小光载荷时才压缩。
- **文本片段** — 粘贴或输入（最多 16 KB），点**启动文本流**。

流式传输中，状态行显示 *Streaming ⟨name⟩ — Share receiver link*；链接打开一个对话框，里面有接收页的 QR、可复制的 URL 和系统分享面板。

**点 QR 码进入全屏**——到设备允许的最大尺寸。再点一下（或 Esc）缩回。更大的物理码让接收端可以坐得更远，或解码更密集的帧。

让屏幕亮度保持最高。码流永远循环，没有"结束"——接收端自己会完成。

## 传输设置

改动任何一项都会重启码流；接收端会根据新会话 ID 自动重置。面板底部的网格显示各旋钮产生的结果（QR 版本、喷泉块数 K、压缩）。

| 设置 | 默认 | 说明 |
|---|---|---|
| 发送 fps | 60 | 为 120 Hz 发送端调优；60 Hz 屏幕上如果接收端卡顿降到 24–30 |
| 字节/帧 | 2953（QR v40） | 密度上限——近距离手机对手机最佳；显示器或远距离退到 1465（v27） |
| 纠错 | L | 喷泉层处理擦除；这个尺寸下 L 是正确的取舍 |
| 显示尺寸 | 900 px | 受屏幕限制；全屏忽略它 |

默认值偏向最佳情况演示。如果传输爬行：字节/帧 → 1465，发送 fps → 24，按这个顺序。
